# Изменения

## Следующая версия — не выпущена

Интерфейс перестроен, чтобы вместить новые функции: вместо трёх вкладок — страницы в боковом меню. Адреса прежних страниц не изменились.

- **Компоновки.** Три на выбор в «Оформлении»: боковое меню (по умолчанию), вкладки, вокруг сайта. В верхней панели слева — сам интерфейс, справа — nfqws2: версия, состояние, перезапуск и остановка.
- **Обзор** стал отдельной страницей с четырьмя видами: группы, плитки, кладка, панель.
- **Диагноз блокировки.** Роутер по шагам выясняет, чем заблокирован сайт: подмена DNS (сравнение с защищённым DNS Яндекса и Google), блокировка по IP, по имени сайта, заморозка «16–20 КБ» — и говорит, поможет ли подбор стратегии.
- **Уточнение в подборе.** Если ни одна стратегия не открывает сайт каждый раз, подбор сам перебирает у лучшей способ порчи фейка, число фейков (до 20) и подставное имя. Порядок перебора зависит от того, как рвётся соединение без обхода. Подбор не стартует, если имя сайта не находится или адрес не отвечает.
- **История подборов.** Что и когда работало для каждого сайта; «Проверить снова» — быстрый подбор только по уже работавшему. Работавшие стратегии подбор пробует первыми.
- **Автоподбор при поломке.** Сайт из мониторинга перестал открываться — роутер сам подбирает стратегию и предлагает её или, если разрешить, применяет отдельным профилем только для этого сайта, с проверкой и откатом. По умолчанию выключен.
- **Причина, когда nfqws2 не работает:** что именно не так и что с этим сделать.
- **Предупреждение о других обходчиках**, работающих одновременно.
- **Обмен профилями:** «Для чата» у профиля и «Вставить чужой» с проверкой и пробным прогоном на сайте.
- **Отчёт для помощи:** текст без секретов для вопроса в чате или issue.
- **Список по ASN:** адреса сети хостинга по номеру AS или по имени сайта, с ежедневным обновлением.
- «Списки» и «Профили» приведены к одному виду; Telegram-уведомления вынесены на отдельную страницу.
- Интерфейс замечает, что браузер показывает старую версию страницы из кеша, и предлагает перезагрузить. Номер сборки виден в «О программе».
- Значок приложения — знак ZD.

## 1.4.0 — 2026-10-04

- Установка на Keenetic с Entware — экспериментально. Команда установки та же, установщик сам определяет систему и ставит отдельный пакет `nfqws2-ui_<версия>-1_all_entware.ipk`: всё лежит под `/opt`, вход — под root из Entware. Обновление кнопкой и из консоли, HTTPS, порт и соседство с nfqws-keenetic-web работают так же, как на OpenWrt. Проверено на стенде с Entware, не на настоящем роутере; отличия и ограничения — в README, раздел «Keenetic (Entware)».
- Lua-скрипты, которые nfqws2-keenetic 1.3.1 ставит сжатыми (`zapret-lib.lua.gz`), больше не считаются отсутствующими. Раньше на свежей установке проверка конфига писала «Файла нет» для каждого `--lua-init`, список скриптов в «Параметрах запуска» был пуст, а параметры lua-функций не проверялись.
- `nfqws-ui-setup` больше не требует `jsonfilter`.

## 1.3.0 — 2026-09-30

- Проверки сайтов замечают ограничение ТСПУ «16-20 КБ»: соединение с зарубежным хостингом (Hetzner, DigitalOcean, OVH, Contabo…) зависает после ~16–20 КБ. Раньше такой сайт считался открытым, если успели прийти заголовки. Теперь «Проверить сайт», мониторинг и тесты стратегий пишут «соединение зависает на объёме» и объясняют, что с этим делать. Маленькие страницы проверяются так же, как в чекере [dpi-checkers/tcp-16-20](https://hyperion-cs.github.io/dpi-checkers/ru/tcp-16-20/): отправкой 64 КБ в отдельном соединении.
- Кнопка в уведомлении («Перезапустить с проверкой» и др.) в узкой боковой колонке переносится под текст. Раньше она вылезала за край, а текст сжимался в столбик.
- Тест стратегий берёт для каждой проверки случайный порт из тестового диапазона. Раньше соединения шли подряд с одних и тех же портов, и на результат мог влиять остаток предыдущего соединения.

## 1.2.1 — 2026-09-29

- `nfqws-ui update vX.Y.Z --force` действительно переустанавливает ту же версию: раньше opkg отвечал «up to date» и ничего не делал.

## 1.2.0 — 2026-09-29

- Проверка обновлений. Интерфейс проверяет новые версии на GitHub при открытии (раз в 12 часов) и раз в сутки по расписанию. Если вышла новая версия, сверху появляется плашка «Что нового / Обновить».
- Обновление из интерфейса с живым журналом установки. После обновления страница перезагружается сама.
- Команда `nfqws-ui-setup update [--check] [vX.Y.Z] [--force]` и `version`. Короткое имя команды — `nfqws-ui`, например `nfqws-ui update`.
- «Настройки → О программе»: версия, ссылки, ручная проверка обновлений, команды для консоли.
- Справка (README) и изменения по версиям открываются прямо в интерфейсе: «Настройки → Справка» и «Изменения по версиям». Описание релиза в окне обновления тоже с оформлением.
- Ссылка на репозиторий в шапке.
- Подсветка журналов (системный журнал, файлы журналов, трассировка, журнал обновления): время, уровень, процесс, пути, файлы, параметры, адреса, ошибки и предупреждения.
- Интерфейс провайдера: кнопка «Определить автоматически» (по маршруту по умолчанию) и выбор из интерфейсов роутера. Для каждого видны адрес, имя в OpenWrt (wan, lan…) и есть ли через него интернет. Если указанного интерфейса на роутере нет, интерфейс об этом предупредит.
- «Параметры запуска»: добавление из списков — lua-скрипты из `lua/`, файлы блобов из `blobs/`, общие параметры nfqws2 из его справки. В списках только то, чего ещё нет. Параметры, которые ломают запуск или задаются init-скриптом, не предлагаются.
- «Проверить сайт»: кнопка «Проверить →» вместо лупы, результат можно свернуть.
- Выравнивание иконок и подписей, строк форм и таблиц. Узкая колонка третьего оформления и шапка на средних ширинах экрана больше не вылезают за край.

## 1.1.0 — 2026-09-29

- Конфиг с другой системы: интерфейс распознаёт конфиг с Keenetic (Entware), из zapret2 и от nfqws первой версии и предлагает «Исправить под OpenWrt»:
  - пути переносятся в `/etc/nfqws2`;
  - интерфейс провайдера, которого нет на роутере, заменяется интерфейсом маршрута по умолчанию;
  - добавляются недостающие переменные и подключаются нужные lua-файлы.

  В редакторе «Конфиг целиком» правки сначала попадают в текст, сохраняет пользователь.
- Предупреждение о стратегиях nfqws первой версии (`--dpi-desync`).
- Кнопка «Подключить <файл>.lua» у замечания «функция из файла, который не подключён через --lua-init».
- Комментарии внутри кавычек (как в стандартном конфиге Keenetic) теперь заметка, а не ошибка. «Удалить комментарий» убирает всю строку, а не только `#`.

  - автоисправление, поиск дубликатов и конфликтов.

- Проверка конфига по `nfqws2 --help`, документации lua-функций и `nfqws2 --dry-run`; кнопки «Исправить».
- Снимки, история изменений с откатом, «Отменить», безопасный перезапуск с автооткатом через 3 минуты.
- Тесты стратегий на отдельной очереди, трассировка с `--debug`, мониторинг с уведомлениями в Telegram.
- Пакет для OpenWrt 24.10, установщик одной командой, утилита `nfqws-ui-setup` (порт, HTTPS, takeover порта 90, вход, cron).
- Вход только под root с паролем, защита от перебора.
